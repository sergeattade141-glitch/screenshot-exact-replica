# WIL WOL AI

**Plus qu’un planning. Ton assistant.**

WIL WOL AI est un projet d’assistant conversationnel personnel conçu pour proposer une interface moderne permettant d’interagir par texte et par voix, avec l’objectif de prendre en charge des moteurs d’intelligence artificielle en ligne et locaux.

Le projet est actuellement en développement. La première phase est consacrée à la création de l’interface utilisateur et aux fonctionnalités de gestion des conversations.

## 🎯 Objectifs du projet

* Concevoir une interface conversationnelle moderne et intuitive.
* Permettre la gestion et la conservation de l’historique des conversations.
* Intégrer des fonctionnalités de saisie vocale et de lecture à voix haute.
* Préparer une architecture capable d'accueillir des moteurs d'IA en ligne et locaux.
* Étudier des solutions adaptées aux ordinateurs disposant de ressources matérielles limitées.

## ✨ Fonctionnalités disponibles

* Création, renommage et suppression des conversations.
* Copie et nouvelle tentative d'envoi des messages.
* Possibilité d'arrêter une génération.
* Conservation de l'historique dans le navigateur.
* Thèmes clair, sombre et système.
* Modes en ligne et local disponibles dans l'interface.
* Dictée vocale via les fonctionnalités du navigateur.
* Lecture vocale avec réglage de la voix, de la vitesse et du volume.
* Effacement des données locales.
* Pages consacrées à la confidentialité et aux conditions d'utilisation.

**État actuel :** l'interface est développée, mais les moteurs d'IA ne sont pas encore intégrés. L'application ne simule pas de réponses générées par une intelligence artificielle.

## 🛠️ Technologies et environnement de développement

Le projet utilise un environnement JavaScript moderne avec Bun pour la gestion des dépendances et l'exécution des commandes de développement.

Les technologies exactes utilisées dans l'application sont à consulter dans les fichiers de configuration et le code source du dépôt.

## 🚧 Feuille de route

* **Phase 1 :** interface utilisateur et gestion des conversations.
* **Phase 2 :** création de comptes utilisateurs.
* **Phase 3 :** intégration d'un moteur d'IA en ligne.
* **Phase 4 :** intégration d'un moteur local sans Ollama.
* **Phase 5 :** prise en charge de la voix hors ligne.

Ces fonctionnalités constituent des objectifs de développement et ne sont pas présentées comme déjà opérationnelles.

## 💻 Lancer le projet en local

### Prérequis

* Bun installé sur l'ordinateur.
* Git pour récupérer le dépôt.

### Installation

Cloner le dépôt :

```bash
git clone https://github.com/sergeattade141-glitch/screenshot-exact-replica.git
cd screenshot-exact-replica
```

Installer les dépendances :

```bash
bun install
```

Démarrer le serveur de développement :

```bash
bun run dev
```

Exécuter les tests :

```bash
bunx vitest run
```

## ⚠️ Limites connues

* La dictée vocale du navigateur peut envoyer l'audio à un service en ligne.
* Les moteurs d'IA ne sont pas encore intégrés.
* Le moteur local reste à développer et devra être adapté aux ressources matérielles disponibles.
* Les comptes utilisateurs et la voix hors ligne sont prévus dans les prochaines phases.
